# 설계 결정

## 2026-11-10

- 프로젝트 문서는 `doc/`에 모은다. 루트의 `AGENTS.md`는 Codex가 작업 규칙을 찾도록 안내하고, 규칙 본문은 한 곳에서 관리한다.
- Git 기본 브랜치는 `main`을 사용한다. 로컬과 GitHub에서 같은 브랜치 이름을 사용한다.
- GitHub 저장소는 사용자 요청에 따라 비공개로 유지한다.

- 공식 그누보드5 5.6.48과 배포 커밋을 고정한다. 로그인, 회원가입, 게시판 권한과 CRUD에는 그누보드 기본 기능을 사용하고, 기본 `free` 게시판에 샘플 권한을 적용한다.
- PHP는 안정판 8.5.12 이상인 8.5 계열을 사용한다. PHP2Shell 두 건의 수정이 포함된 계열이고, 그누보드7의 Composer PHP 요구사항인 `^8.2` 범위에 속한다.
- 웹 서버는 로컬 루프백에만 바인딩한다. 로컬 라우터에서 데이터 디렉터리로의 직접 접근과 설치 완료 후 설치 경로를 차단한다.
- 홈페이지와 ERP의 경계를 실습하기 위해 그누보드5에서 별도 루프백 HTTP 서버의 주문 API를 호출한다. 모의 서버는 도서 전집과 가상 판매처를 담은 고정 JSON을 제공한다. 주문은 기존 그누보드 회원 세션으로 보호하는 조회 전용 예제다.
- 아람북스의 두 단계 상단 메뉴를 유지하고 전집 탭·목록 상세·분류를 페이지 안의 세 번째 단계로 제공한다. 세 단계 모두 직접 열 수 있는 URL을 갖는다. 샘플 메뉴와 본문은 PHP 데이터로 구성해 추가 DB 설치 없이 탐색할 수 있게 하고, 그림책 표지·게시글·판매처는 데모 자료를 사용한다. 기존 그누보드 게시판, 회원 기능, ERP 조회는 하단 링크로 연결한다.

## 2026-11-12

- 사용자 요청에 따라 아람북스 메뉴와 본문을 그누보드와 같은 DB의 전용 `aram_content` 테이블로 옮겼다. 접두사는 그누보드 설정을 사용한다. 기존 3단계 URL을 유지하기 위해 대메뉴별 JSON 데이터를 저장하며, 웹 요청은 그누보드 SQL 함수로 조회한다. 초기화 스크립트는 기존 행을 보존한다.
- 홈페이지 하단에서 샘플 게시판, ERP 주문 조회, 로그아웃 링크를 제거했다.

- 사용자 요청으로 브랜드를 우람북스로 바꾸고 차일드올·오징어빵·산수특공대 등 가상 명칭을 적용했다. 기존 DB의 문자열 값은 초기화 명령에서 트랜잭션으로 변환하며 URL과 데이터 키를 보존한다.
- 영어 전집 메뉴는 ENGLISH READ TIME으로 표기한다. 하위 전집은 ENGLISH READ TIME AT HOME으로 맞추고 긴 메뉴명에 맞춰 모바일 메뉴 전환 폭을 조정했다.
- 영아 전집 메뉴는 아기올로 표기하며 같은 이름을 사용하는 하위 전집·교구도 함께 변경한다.
- 프리스쿨&스쿨 전집 9개 이름은 사용자 지정 표기를 따른다. 목록과 상세 본문을 함께 변환하며 기존 탐색 URL은 유지한다.
- 소통 메뉴의 표시명은 사용자 요청을 교감해요 및 고객센터로 해석하여 적용했다. 작은 책 모음과 교육용 장난감은 하위 메뉴와 DB 본문에도 사용한다.

## 2026-11-14

- 우람북스 화면을 `theme/uram` 전용 테마로 옮겼다. 문서 시작·끝에도 공통 레이아웃을 연결해 회원 화면과 게시판에 적용하며 기본 스킨을 재사용한다. 반응형 화면에 PC 스킨을 사용하고 테마 변수와 JavaScript 모듈을 분리해 그누보드 전역과 충돌을 방지한다. 기존 URL은 쿼리를 보존해 홈페이지로 연결한다.

## 2026-11-16

- 서버 배포는 별도 Compose 프로젝트와 앱 루프백 포트, DB·data 전용 영속 볼륨으로 구성한다. 공식 그누보드 커밋과 PHP 8.5.12·MariaDB 11.4.13을 고정한다.
- 새 서버는 새 DB에 데모 데이터를 설치한다. 공식 설치 스크립트를 CLI로 실행하고 비밀번호는 서버의 비밀 파일에서 읽는다. 실제 로컬 회원·설정 파일은 전송하지 않는다.
- 호스트 Caddy는 전용 사이트 파일만 추가하고 전체 검증 성공 후 reload한다. 메인 설정·SSH·방화벽·다른 Compose 프로젝트는 수정하지 않는다.
- 기존 ERP 조회 예제는 컨테이너 내부 API 주소를 환경 변수로 선택하고 로컬 기본값을 유지한다.
- 재기동 시 관리자가 변경한 테마·게시판 설정을 보존하도록 최초 환경설정은 영속 data 폴더의 표시 파일을 사용해 한 번만 적용한다.

## 2026-11-17 · 공통 스크립트와 CAPTCHA

- 그누보드 기본 JavaScript는 원래의 동기 로딩과 전역 함수를 유지한다. jQuery에 즉시 의존하는 회원가입 스킨과 CAPTCHA가 있으므로 모듈·defer로 바꾸지 않는다. 전역 이름 충돌 방지는 테마의 `site.js`만 모듈로 격리해 처리한다.
- data/cache는 기본 비공개를 유지하며, 그누보드가 생성하는 `kcaptcha-[32자리 16진수]_[숫자].mp3` 경로만 공개한다. PHP 실행·세션·설정 파일 차단은 유지한다.

## 2026-11-18 — 고정 PHP 이미지에서도 Apache 보안 업데이트를 강제한다

- PHP 8.5.12 기반은 유지하며 공식 Debian 저장소에서 Apache 패키지 네 개를 업데이트한다. 요청된 2.4.69 이상을 충족하고 후속 보안 수정이 포함된 2.4.71을 최소 빌드 기준으로 삼는다.
- 운영 컨테이너 안에서 일시적으로 apt를 실행하는 대신 Dockerfile을 수정하고 이미지를 재빌드해 재배포 후에도 업데이트를 유지한다.
- 웹 앱과 내부 ERP가 같은 이미지 구성을 사용하므로 둘 다 새 이미지로 교체한다. DB와 업로드 볼륨 및 PHP 버전은 유지한다.
- 기존 이미지는 명시적인 롤백 태그로 보관한다. 일반 local·latest 태그는 새 이미지를 가리킨다.

## 2026-11-21 — PHP 최소 버전을 8.5.13으로 올린다

- KISA 인터넷 보호나라 보안공지(2026-11-19, PHP 취약점 18건)에서 8.5 브랜치는 8.5.13 미만이 영향 대상이며 해결 버전은 8.5.13이다. 이 프로젝트는 8.5.12를 사용하므로 해당된다. 8.5 브랜치에만 해당하는 UAF·정수 오버플로우 항목도 포함되어 있다.
- 브랜치를 바꾸지 않고 같은 8.5 계열의 패치 버전만 올린다. 그누보드5 호환성과 기존 검증 범위를 유지하기 위해서다.
- Docker 기본 이미지는 Docker Hub에서 정식 태그 `8.5.13-apache-bookworm`을 확인한 뒤 고정하고, 로컬 실행 검사(`check-php.php`)의 최소 버전도 같게 맞춘다. 운영 컨테이너 안에서 임시 패치하지 않고 이미지 재빌드로 반영한다.
- 이전 롤백 가능성을 위해 서버 배포 시 기존 이미지를 롤백 태그로 보관하는 Apache 패치 때의 절차를 따른다.
