# 설치 및 실행

## 저장소 가져오기

Git과 비공개 저장소에 접근할 수 있는 GitHub 계정이 필요하다. 아래 명령으로 작업 폴더를 가져온다.

```sh
git clone https://github.com/songsunglyong/gnu_board5.git
cd gnu_board5
```
