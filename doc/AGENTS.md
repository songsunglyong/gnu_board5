# Codex 작업 규칙

1. 작업을 시작하기 전에 이 문서와 [PROJECT.md](PROJECT.md), [TODO.md](TODO.md), [DECISIONS.md](DECISIONS.md)를 읽는다.
2. 현재 파일 구조와 Git 상태를 확인하고 기존 사용자 변경을 보존한다.
3. 요청 범위에 맞게 수정하고 관련 명령이나 테스트로 결과를 확인한다. 확인할 수 없는 항목과 이유는 작업 결과에 남긴다.
4. 설계 결정이 생기면 배경과 이유를 [DECISIONS.md](DECISIONS.md)에 기록한다. 구조나 설치·실행 방법이 바뀌면 해당 문서도 갱신한다.
5. 작업이 끝나면 [TODO.md](TODO.md)의 완료 및 미완료 상태와 [CHANGELOG.md](CHANGELOG.md)의 완료 내역을 갱신한다.
6. 비밀번호, API 키, 운영 환경 설정값은 Git에 커밋하지 않는다.
