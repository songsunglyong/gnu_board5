# 변경 이력

## 2026-11-10

- `doc/`에 프로젝트 설명, 작업 규칙, 할 일, 변경 이력, 설계 결정, 설치·실행 안내를 추가했다.
- 루트의 `AGENTS.md`에서 `doc/AGENTS.md`를 안내하도록 했다.
- 로컬 Git을 `main`으로 초기화하고 GitHub 비공개 저장소를 `origin`으로 등록했다.
- 공식 그누보드5 5.6.48을 준비하는 스크립트와 샘플 시작 화면을 추가했다. 기본 게시판과 회원 기능으로 로그인·로그아웃 및 게시글 작성·조회·수정·삭제를 제공한다.
- PHP 8.5.12 이상인 안정판 8.5.x와 필수 확장을 시작 전에 검사한다. PHP 8.5.12 및 MariaDB 11.4.13에서 HTTP로 설치와 일반 회원 CRUD를 확인했다.
- 이 Mac에서 샘플 미리보기를 시작하고 8080 포트에서 홈페이지와 게시판 응답을 확인했다.
- 도서 전집 ERP 모의 API와 로그인 회원용 주문 조회 화면을 추가했다. 판매처와 주문 상태를 필터링하고 취소 주문을 제외한 금액을 집계한다.
- 아람북스 메뉴를 참고한 그누보드5 홈페이지 샘플을 추가했다. 7개 대메뉴, 모바일 하위 메뉴, 3단계 상세 경로, 전집 검색을 제공한다.
