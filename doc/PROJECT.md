# gnu_board5 프로젝트

그누보드5로 로그인과 게시글 작성·조회·수정·삭제 흐름을 실습하는 로컬 샘플이다. 누구나 게시글을 읽을 수 있고, 로그인한 일반 회원은 글을 작성하고 자신의 글을 수정·삭제할 수 있다. 관리자는 그누보드의 기본 관리 권한을 사용한다.

- `sample/index.php`는 우람북스 데모 홈페이지이며 그누보드5의 DB 연결과 조회 함수를 사용한다.
- `scripts/`는 공식 그누보드5 준비, PHP 버전 검사, 샘플 게시판 설정, 로컬 서버 실행을 담당한다.
- `.runtime/gnuboard5/`에는 공식 배포 소스와 설치 시 생성되는 데이터가 들어간다. 이 디렉터리는 Git에서 제외한다.
- `doc/`는 프로젝트 문서이며, 루트 `AGENTS.md`에서 작업 규칙으로 연결한다.

로그인한 회원은 `sample/orders.php`에서 도서 전집과 가상 판매처의 주문을 조회할 수 있다. PHP가 `sample-erp/`의 로컬 JSON API를 호출하고, 판매처와 상태 필터를 적용해 주문 건수와 취소 제외 금액을 표시한다.

홈페이지는 우람북스라는 가상 출판사의 7개 대메뉴와 하위 메뉴를 그누보드5 로컬 샘플로 제공한다. 전집 상세 탭, 소전집·교구 상품 상세, 소식 글, FAQ 분류, 소개 섹션 및 판매처 지역을 세 번째 단계에서 열 수 있다. 메뉴와 본문은 그누보드 DB의 `g5_aram_content` 테이블에 저장한다. `sample/aram/catalog.php`가 매 요청마다 그누보드 SQL 함수로 조회하고 홈페이지와 상세 화면에서 공유한다.
