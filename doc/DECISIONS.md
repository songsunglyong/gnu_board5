# 설계 결정

## 2026-11-10

- 프로젝트 문서는 `doc/`에 모은다. 루트의 `AGENTS.md`는 Codex가 작업 규칙을 찾도록 안내하고, 규칙 본문은 한 곳에서 관리한다.
- Git 기본 브랜치는 `main`을 사용한다. 로컬과 GitHub에서 같은 브랜치 이름을 사용한다.
- GitHub 저장소는 사용자 요청에 따라 비공개로 유지한다.

- 공식 그누보드5 5.6.48과 배포 커밋을 고정한다. 로그인, 회원가입, 게시판 권한과 CRUD에는 그누보드 기본 기능을 사용하고, 기본 `free` 게시판에 샘플 권한을 적용한다.
- PHP는 안정판 8.5.12 이상인 8.5 계열을 사용한다. PHP2Shell 두 건의 수정이 포함된 계열이고, 그누보드7의 Composer PHP 요구사항인 `^8.2` 범위에 속한다.
- 웹 서버는 로컬 루프백에만 바인딩한다. 로컬 라우터에서 데이터 디렉터리로의 직접 접근과 설치 완료 후 설치 경로를 차단한다.
- 홈페이지와 ERP의 경계를 실습하기 위해 그누보드5에서 별도 루프백 HTTP 서버의 주문 API를 호출한다. 모의 서버는 도서 전집과 가상 판매처를 담은 고정 JSON을 제공한다. 주문은 기존 그누보드 회원 세션으로 보호하는 조회 전용 예제다.
- 아람북스의 두 단계 상단 메뉴를 유지하고 전집 탭·목록 상세·분류를 페이지 안의 세 번째 단계로 제공한다. 세 단계 모두 직접 열 수 있는 URL을 갖는다. 샘플 메뉴와 본문은 PHP 데이터로 구성해 추가 DB 설치 없이 탐색할 수 있게 하고, 그림책 표지·게시글·판매처는 데모 자료를 사용한다. 기존 그누보드 게시판, 회원 기능, ERP 조회는 하단 링크로 연결한다.

## 2026-11-12

- 사용자 요청에 따라 아람북스 메뉴와 본문을 그누보드와 같은 DB의 전용 `aram_content` 테이블로 옮겼다. 접두사는 그누보드 설정을 사용한다. 기존 3단계 URL을 유지하기 위해 대메뉴별 JSON 데이터를 저장하며, 웹 요청은 그누보드 SQL 함수로 조회한다. 초기화 스크립트는 기존 행을 보존한다.
- 홈페이지 하단에서 샘플 게시판, ERP 주문 조회, 로그아웃 링크를 제거했다.

- 사용자 요청으로 브랜드를 우람북스로 바꾸고 차일드올·오징어빵·산수특공대 등 가상 명칭을 적용했다. 기존 DB의 문자열 값은 초기화 명령에서 트랜잭션으로 변환하며 URL과 데이터 키를 보존한다.
- 영어 전집 메뉴는 ENGLISH READ TIME으로 표기한다. 하위 전집은 ENGLISH READ TIME AT HOME으로 맞추고 긴 메뉴명에 맞춰 모바일 메뉴 전환 폭을 조정했다.
- 영아 전집 메뉴는 아기올로 표기하며 같은 이름을 사용하는 하위 전집·교구도 함께 변경한다.
- 프리스쿨&스쿨 전집 9개 이름은 사용자 지정 표기를 따른다. 목록과 상세 본문을 함께 변환하며 기존 탐색 URL은 유지한다.
- 소통 메뉴의 표시명은 사용자 요청을 교감해요 및 고객센터로 해석하여 적용했다. 작은 책 모음과 교육용 장난감은 하위 메뉴와 DB 본문에도 사용한다.
